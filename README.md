# Student Management System

## Project Overview

The Student Management System is a web-based application used to manage student records easily.

The application allows users to add, view, edit, delete, and search student information.

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub
- GitHub Pages
- Browser Local Storage

## Features

### 1. Add Student
Users can add a new student by entering:

- Student ID
- Student Name
- Email
- Department
- Year

### 2. View Students
All saved student records are displayed in a table.

### 3. Edit Student
Users can edit existing student information.

### 4. Delete Student
Users can delete a student record after confirmation.

### 5. Search Student
Users can search students using:

- Student ID
- Name
- Email
- Department

### 6. Data Storage
Student records are stored using browser Local Storage.

## CRUD Operations

| Operation | Description |
|---|---|
| Create | Add a new student |
| Read | Display student records |
| Update | Edit student information |
| Delete | Remove a student record |
